# SeatView 프로젝트 규칙 (Project Rules)

이 프로젝트에서는 다음의 사용자 정의 저장 및 업데이트 규칙을 엄격히 준수합니다.

1. **저장 명령어 규칙**
   - 사용자가 **"저장해줘"**라고 명시적으로 말할 때만 작업 내용을 영구적으로 저장(Persist/Save)합니다.
   - 사용자가 **"만들어줘"**, **"html 작성해줘"** 등과 같이 구현 또는 생성을 지시할 때는, 이전에 **저장해 둔 내용**을 기반으로 HTML/CSS/JS 파일에 반영하여 업데이트합니다.
   
2. **비저장 상태 유지**
   - 위의 두 명령어("저장해줘", "만들어줘" 등)를 직접 사용하지 않았을 때는 파일 내용을 임의로 저장하거나 업데이트하지 않습니다.
